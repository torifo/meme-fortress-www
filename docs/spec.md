# 電脳ミーム要塞 仕様書

## 1. 概要

- **コンセプト:** ネットの荒波（SNS）から伝説のネタ（ミーム）を「自力で獲る」「削って暴く」「集めて誇る」体験。
- **ターゲット:** ネットスラング好き、バーチャル空間利用者、コロコロコミックのノリを愛する全世代。
- **デザイン指針:** 既存のデザインベースを基調としつつ、過剰なまでの装飾（太い縁取りフォント、原色、爆発エフェクト、擬音）を追加する。

---

## 2. 主要機能（システム要素）

### ① 爆速スクロール・スナッチ（獲得フェーズ）

ガチャに代わる「実力（とタイミング）で掴み取る」獲得システム。

- **概要:** 巨大モニターに激流のごとく流れるSNS投稿（X, Instagram, TikTok, Facebook風のデザイン）から、特定の投稿を「スナッチ（捕獲）」する。
- **アクション:** タイミングを合わせてボタン（またはアバターのパンチ等）を入力。
- **演出:** 成功時に「ズババババ！」「GET!!」の巨大文字と爆発エフェクト。
- **成果物:** 「未開封・銀はがしポストカード」としてインベントリに保存。

### ② 禁断の銀はがしアクション（開封フェーズ）

スロットに代わる「期待感の持続」と「快感」の提供。

- **概要:** 獲得したポストカードの重要部分（ネタの核心やレア画像）を、マウスやコントローラーで削って公開する。
- **アクション:** スクラッチ部分をなぞる動作。削った面積に応じて「カリカリ」というSEを再生。
- **演出:** 全部削り終えた瞬間に「衝撃の真実！」「神バズり確定！」などの煽り文句と共にフルカラー化。
- **内容物:** ネットスラングの解説、小ネタ画像、または空間で使える「ふろく」の当選通知。

### ③ 電脳ミーム大百科（コレクションフェーズ）

- **概要:** 収集したカードを閲覧・展示するスクラップブック機能。
- **機能:** カテゴリ別（例：絶望のTwitter、映えのインスタ）のファイリング、他ユーザーへの公開。
- **称号システム:** 収集数や「銀はがし」の達成度に応じて、ユーザー名の上に「伝説の廃人」「ミームの覇者」などのド派手な称号を表示。

---

## 3. デザイン・演出要件（コロコロ・エッセンス）

| 要素 | 仕様詳細 |
| :--- | :--- |
| **フォント** | 太めの角ばったフォント（ラグランパンチ等）を使用。基本は3重の縁取り（白・黒・赤など）。 |
| **煽り文句** | すべてのUI要素に「超絶」「衝撃」「爆誕」「禁断」等の枕詞を自動付与。 |
| **エフェクト** | 決定・成功時は画面全体が揺れる（スクリーンシェイク）と、集中線の合成。 |
| **効果音 (SE)** | 昭和〜平成初期のホビーアニメのような、金属音と爆発音をミックスした重厚な音。 |

---

## 4. コンテンツ構造（SNSエリア別）

### 「X（旧・青い鳥）の樹海」

- **内容:** 140文字の毒舌、伝説のコピペ、大喜利。
- **付録:** アバターの頭上に浮かぶ「炎上エフェクト」。

### 「インスタ・シャイニング・マウンテン」

- **内容:** 過剰に加工された画像、キラキラしたスラング。
- **付録:** 歩くたびに背後からバラが散る「映えオーラ」。

### 「TikTok・バースト・ステージ」

- **内容:** 15秒の狂気、流行のダンス（のパロディ）、倍速音声。
- **付録:** アバターが常に倍速で動く「高速ダンス・シューズ」。

---

## 5. 技術的検討事項（開発ガイドライン）

- **ベースブランチの活用:** 既存のバーチャル空間基盤に対し、オーバーレイUIとしてコロコロ風フレームを実装する。
- **ポストカードの動的生成:** ネットのネタをカード化する際、テンプレートに対してテキストと画像を合成するシェーダーまたはスクリプトを構築。
- **「削り」のロジック:** マスクテクスチャをペイント操作で透過させる処理を実装し、剥離率を計算する。
